# blend_logo_animation

Creator: <dinesh_blend360_india> <dinesh.marre@blend360.com>

A transparent, looping Blend logo animation for loading screens.

- [TypeScript React component](blend-logo-animation-tsx-cmp/README.md): copy this folder into an existing React app.
- [Full set](blend-logo-animation/README.md): TypeScript, JavaScript, standalone HTML, and an optional loading-turn hook.

The component uses React 18 or newer. It needs no separate animation package or npm command in an existing app.
